FAQ

Questions fréquentes

Quels moyens de paiement acceptez-vous ?

Uniquement PayPal. Après validation de ta commande, un bouton te redirige vers PayPal avec le montant exact.

À quoi sert le code de commande ?

Il identifie ta commande. Indique-le dans la note du paiement PayPal et envoie-le au support pour que l'on retrouve ton paiement.

Quel est le délai de livraison ?

La livraison commence une fois le paiement vérifié. Si ta commande tarde, contacte le support avec ton code.

Que dois-je fournir pour un boost de serveur ?

Le nom ou l'invitation de ton serveur. Nous ne demandons jamais ton mot de passe ni ton code d'authentification.

Puis-je être remboursé ?

Si une commande ne peut pas être livrée, elle est remboursée. Les conditions détaillées sont à définir dans tes CGV.

Êtes-vous affilié à Discord ?

Non. Ce site est indépendant et n'est ni affilié, ni approuvé, ni sponsorisé par Discord Inc.

Une question avant de commander ?

Écris-nous, on te répond avec plaisir.
